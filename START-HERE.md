# Start here

## Key takeaway

Choose one real question and the smallest established technique that helps answer it.

## Summary

This is a usable knowledge library, not a required sequence of frameworks. Start with a question, select a Method, and use a Practice when several operations and decisions need to be coordinated.

## Three starting points

| Your situation | Start | What to produce |
|---|---|---|
| The problem is vague | [5W2H](methods/5w2h.md) | Context and significant unknowns |
| Several technologies look promising | [Opportunity Practice](practices/investigate-a-technical-opportunity.md) | Evidence-qualified alternatives and a bounded next action |
| You need to show a multiattribute comparison | [Radar chart](methods/radar-chart.md) | Raw and mapped data with interpretation limits |

## A first complete route

Read the relevant stage of [Investigation](practices/discover-and-validate-a-technical-insight.md). It contains the immediate reasoning and procedure; links provide depth. Use a factual problem statement, collect real evidence, compare rival explanations, choose an authorized check and preserve uncertainty. An honest unresolved result is better than a confident invented cause.

## What not to do

Do not apply all 22 Methods. Do not call brainstorming evidence, visual area utility or a TRL an adoption recommendation. Do not create our own standalone Method merely to describe a broad task; place that orchestration in the relevant Practice.
