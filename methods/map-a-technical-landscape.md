# Map a technical landscape

## Key takeaway

Explore mechanisms and alternatives around a goal before treating the first plausible solution as the only one.

## Summary

Use this for opportunity discovery or an unfamiliar area. The output is a compact map of capability gaps, established explanations, candidate approaches and decision-relevant unknowns, not a catalogue of everything published.

## Inputs and prerequisites

A scoped purpose, initial search vocabulary, access constraints and an explicit research budget. Search access can be incomplete; record the scope rather than claiming exhaustive novelty.

## Rationale

A solution-first search can hide alternatives. Comparing how different approaches address the same need exposes distinct mechanisms and tradeoffs. Source families also reveal whether apparent consensus is repeated reporting.

## Procedure

1. Describe the target capability and limiting constraint without naming a technology.
2. List alternative mechanisms or approaches, including no change, a simpler existing method and changes to the operating context.
3. Search authoritative source material for the question: definitions, measured performance, mechanism evidence, limitations and failed approaches. Use several search phrasings and record important exclusions.
4. For each approach record mechanism, applicability, evidence type, maturity, constraints and unresolved assumptions. Identify common upstream data or guidance.
5. Look for a boundary mismatch: a result true for a different scale, duty cycle, user group or endpoint may suggest a test, not a transferable conclusion.
6. Rank questions by their ability to eliminate an option or reveal a viable one. Select a discriminating analysis rather than merely the most fashionable approach.
7. Write what is known elsewhere, what is new to this project and what remains unsearched. Do not assert field-wide novelty.

## Expected effect

Several technically distinct routes to a need, with explicit evidence gaps and one worthwhile next question.

## Validation and counterevidence

Ask whether the alternatives genuinely differ or are renamed versions of one design. A counterexample is discovering all citations derive from the same untested vendor claim. Revise the map when a missing constraint changes feasibility.

## Limits

A landscape is a bounded desk investigation. It cannot certify intellectual-property freedom or originality. Public source summaries do not authorize reuse of restricted designs or data.
