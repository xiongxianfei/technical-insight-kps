# Transfer

## Key takeaway

Reusing an insight requires checking the new conditions, not copying the old conclusion unchanged.

## Summary

Transfer is application of understanding from a source context to a target context. Relevant similarities include mechanism, units, scale, interfaces, users and operating conditions; surface resemblance is insufficient.

## Definition and distinctions

Map the source claim and its evidence envelope to the target. Identify preserved assumptions, changed assumptions and unobserved dimensions. Decide whether direct adoption, a bounded pilot or rejection is warranted.

## Worked distinction

A payload exclusion policy that fixes a Git checkout may need adjustment for another version-control system. The general distinction between tool state and publication content transfers more readily than its exact directory names.

## Limits

A successful source test does not certify the target. An analogy can generate a hypothesis, not establish it. Domain-independent investigation does not remove the need for discipline-specific expertise.
