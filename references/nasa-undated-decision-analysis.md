## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

Alternative selection involves objectives, evaluation criteria, uncertainties and authorized judgment. Extra information has practical value when it can change the decision enough to justify its cost and delay. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
