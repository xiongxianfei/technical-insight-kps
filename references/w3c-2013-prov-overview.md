# W3C provenance overview

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

Provenance records entities, activities and agents involved in producing information. It provides a basis for inspecting origin and derivation. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
