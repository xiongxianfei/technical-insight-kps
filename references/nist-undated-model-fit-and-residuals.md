# NIST model fit and residual analysis

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

A high fit statistic alone does not establish adequacy. Residuals are differences between observations and predictions; structured residuals can expose inadequacy missed by a single summary number. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
