# Cochrane collecting data guidance

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

Several reports can describe one study. Context and intervention implementation affect interpretation. Extraction should preserve what was actually reported rather than silently reconcile discrepancies. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
