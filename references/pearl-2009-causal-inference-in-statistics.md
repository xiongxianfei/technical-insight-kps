# Causal inference in statistics An overview

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

Associational information does not by itself specify the result of an intervention. Causal conclusions require additional assumptions; diagrams and structural equations can make those assumptions explicit. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
