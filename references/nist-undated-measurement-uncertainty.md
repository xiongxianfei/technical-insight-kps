# NIST essentials of measurement uncertainty

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

A measurement equation describes the measurement process, including significant corrections and variability. Type A and Type B refer to how uncertainty is evaluated, not to a simple random-error/systematic-error split. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
