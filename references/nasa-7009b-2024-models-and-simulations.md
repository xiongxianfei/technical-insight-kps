# NASA standard for models and simulations

## Key takeaway

Use this source for the located contribution, not for claims it did not evaluate.

## Summary

The standard distinguishes intended use, implementation verification, validation against a referent and a domain of validation. Calibration adjusts parameters; applicability also depends on assumptions and verification/validation evidence. The reference identifies the evidence contribution and access limits; it is not a substitute for reviewing the original when the decision requires it.
